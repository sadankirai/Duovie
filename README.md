# Duovie

Duovie is a private, two-person watch-together platform: a Host creates a room, invites one Guest, shares supported screen content, and both participants can chat in real time. It is designed for private one-to-one sessions, not public broadcasting.

**Status:** early foundation; not production ready.

**Planned stack:** .NET 10 / ASP.NET Core / C# / PostgreSQL / SignalR, plus React, TypeScript, Vite, and Node.js 24.

# Duovie agent guidance

The canonical source of truth is [`docs/`](docs/), not this agent-specific file. Before work, read:

1. [`docs/PRODUCT.md`](docs/PRODUCT.md)
2. [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
3. The applicable section of [`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md)
4. Relevant ADRs in [`docs/decisions/`](docs/decisions/)
5. [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md), [`docs/TESTING.md`](docs/TESTING.md), and [`docs/AI_WORKFLOW.md`](docs/AI_WORKFLOW.md)

Never silently change a hard invariant or architectural decision. Keep work within the requested scope, avoid speculative features, and verify changes before reporting completion. These rules apply equally to human contributors and any coding assistant; no tool or vendor owns the project.
